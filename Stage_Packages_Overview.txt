HOW THE CODE WAS CHECKED
  The logic (register, login, items, search, filters, report, detail, history,
  map pins, matching, claim check, home search) was tested with a simulated
  browser: 81 checks passed. It was NOT opened in a real browser, so the first
  real test on your laptop (F12 > Console for errors) is important. Photo
  upload (FileReader and canvas) can only be tested in a real browser.

IF YOU ALREADY OPENED AN EARLIER STAGE IN YOUR BROWSER
  The starting items are copied to localStorage only once. To load the new
  data.js: open the website, press F12, open the Console, type
      resetItems()
  and refresh the page (or: Application > Local Storage > delete "lf_items").
  Accounts are kept in "lf_users", so they stay.
