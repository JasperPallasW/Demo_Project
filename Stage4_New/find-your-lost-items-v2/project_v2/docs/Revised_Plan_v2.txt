10. NOTES AND RISKS
------------------------------------------------------------------------------

  - Data is saved in each browser (localStorage). Another computer will not see
    the same data. Say it honestly: "a real product needs a server and database".
  - Passwords are plain text in the demo. Not safe for real use.
  - File names are case sensitive on Netlify: blackWallet.jpeg is not
    blackwallet.jpeg.
  - style.css must be loaded AFTER Bootstrap.
  - The CSS filters and tabs need a modern browser (:has). Old browsers show all
    items instead.
  - Bootstrap and the icons come from the internet (CDN). Check the live site
    with internet on.
  - Names and origins of the demo finders are made up.
